# 小禾，你家的 AI 家教

陪孩子做作业，也陪孩子把知识想明白。

孩子遇到不会的题，可以说出问题、拍下题目，和小禾一起一步步想。家长可以整理老师的作业通知，选择基础资料或导入自己的课本、讲义，再查看孩子的完成情况与学习过程。

## 能怎样帮到一个家庭

- **卡住时有引导**：文字、语音和图片提问，先说想法，再尝试一个小提示。
- **从资料开始学**：配有14个原创基础单元，也支持导入家庭有权使用的课本、讲义和笔记；不是全套官方教材库。
- **接着问、接着练**：保存作答和提示记录，为后续讲解与练习提供依据。
- **读一段，练一道**：把学习单元编成带测验、闪卡和页内问答的小学习书，建议先从一个小章节开始。
- **微信接上家庭空间**：本人绑定后可聊天、查看作业；用“作业整理”开始收集截图，“发完了”结束，由家长核对后交给孩子。
- **家长看见过程**：查看任务完成、作答和提示记录，不把完成率当掌握率。

手机、平板和电脑通过浏览器进入；Windows自家部署是另一种交付方式，大型克隆语音不属于当前云端套餐。
