# 小禾 家庭作业整理与学习陪伴

小禾是一个独立开发中的家庭学习工具，尝试把每天的作业通知整理、家长确认、孩子执行和进度查看接在一起。

典型流程：

1. 家长上传老师的作业截图。
2. AI辅助整理出作业清单。
3. 家长检查、修改，确认后再交给孩子。
4. 孩子按清单完成任务，遇到问题时获得学习引导。
5. 家长查看完成情况，了解还有哪一步需要帮助。

我们希望减少重复整理和提醒，让孩子更清楚接下来做什么。不着急，每个小进步都算数。

## 当前状态

这是产品介绍仓库，不包含应用源码。公网发布与收费流程仍在验收，暂不通过本仓库售卖账号或收款；公开体验入口、实际可用范围、费用及额度以之后的正式公告为准。

AI整理和学习引导可能出错，关键内容应由家长核对。不承诺提分，不替代教师、家长判断或专业辅导。

## 反馈

欢迎用Issue描述你希望减少的重复工作，或提供脱敏后的操作问题。请只描述操作步骤、设备类型和错误提示，不上传孩子照片、学校班级、作业原图、电话、付款凭证、API密钥或连接码。
